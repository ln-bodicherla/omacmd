# Changelog

## 0.1.0 — unreleased

First version. Tested against Omarchy 4.0.3rc4 / Hyprland 0.56.2 on Asahi (MacBookPro18,1).

- Per-app ⌘/⌥/⌃ shortcuts for terminals, Chromium, Firefox, Nautilus, editors
- Omarchy window-manager bindings moved off ⌘ at load time
- ⌘Tab switcher overlay, Mission Control-style overview, Mac trackpad gestures
- ⌘-click opens links in a new tab
- Raw-input passthrough for games, VMs and remote desktops
- `omacmd` install / uninstall / on / off / doctor / list
